# 🔐 Authentication Architecture

### Registration

```text
User
 │
 ▼
Register API
 │
 ▼
Validate Input
 │
 ▼
bcrypt.hash()
 │
 ▼
Database
 │
 ▼
Account Created
```

### Login

```text
User
 │
 ▼
Login API
 │
 ▼
Find User
 │
 ▼
bcrypt.compare()
 │
 ▼
Generate Access Token
 │
 ▼
Generate Refresh Token
 │
 ▼
Authenticated Session
```

### Protected Request

```text
Client
 │
 │ Authorization: Bearer <access_token>
 ▼
Auth Middleware
 │
 ▼
jwt.verify()
 │
 ├── Invalid → 401
 │
 └── Valid
       │
       ▼
    Controller
       │
       ▼
    Response
```
